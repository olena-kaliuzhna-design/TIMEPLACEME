# TIMEPLACEME — static copy

Static snapshot of https://timeplaceme.world/ (home page) for experimenting with new blocks.

- `index.html` — page markup (inline scripts for menu, map, city vote, consent)
- `assets/frontend.css` — all styles
- `assets/application.js` — site JS bundle (Turbo/Stimulus)
- images: `logo.*`, `figma-assets/`, `map/`, store badges

Notes: links to other pages point to the live site; the city-vote form and analytics don't work in this copy.

Run locally: `python3 -m http.server` then open http://localhost:8000
